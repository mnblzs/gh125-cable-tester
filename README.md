# 常用GH125系列接口线序检测

面向机器人日常维修与调试的 GH125 系列线束测试工具，用于辅助检查线材通断及线序，减少单人逐针使用万用表检查时的操作负担。接口方向和针号应以工程图为准。

## 一、主要功能与硬件组成

| 项目 | 配置或用途 |
| --- | --- |
| 应用场景 | 机器人线束维修与检查 |
| 接口系列 | GH125 |
| 主要用途 | 线材通断和线序检查 |

### 原理图器件与连接器索引

| 位号 | 工程标注 |
| --- | --- |
| U1 | TP4059，充电电路器件 |
| USB1 | TYPE-C 6P(073) |
| CN1、CN2 | GH125-S04DCA-00，4Pin |
| CN3、CN4 | GH125-S02CCA-00，2Pin |
| X1、X2 | GH125 6Pin，不同封装型号 |
| X3、X4 | GH125-S07CCA-00，7Pin |
| CN5 | A1251WR-S-4P-LCP |
| SW1 | MST22D18G2 |

连接器型号同时包含立插/卧插等封装变体，针数一致不代表可直接互换。工具提供连接关系检查，不能替代线束的耐压、绝缘、载流能力或高速通信测试。

## 三、复刻与使用

1. 导入工程，核对原理图、PCB版本、器件型号和封装。
2. 按原理图针号核对供电极性、信号电平及连接器插接方向；不要仅依赖线色或照片判断针序。
3. 制板前执行电气规则与PCB设计规则检查，复核板框、孔位和制造参数。
4. 焊接后先检查短路与器件方向，确认电源正常后再连接外部设备并逐项验证功能。

被测线束应与机器人、电源及其他设备断开后再测试。测试前先用已知正确线束核对各通道，不能仅凭指示结果推断带载能力或信号完整性。

### 调试记录建议

建议记录PCB版本、实际芯片与晶振、供电电压、固件版本、接线照片和测试结果。反馈问题时附上相关位号、复现步骤及预期/实际现象，便于定位。

### 文件与验证状态

本次已完成工程归档、器件属性整理和说明补充。仓库未附独立Gerber、原理图PDF或整板测试报告；需要制造文件时请在核对工程后从EDA重新导出。本次整理没有进行实物上电、精度、通信或保护性能测试。
